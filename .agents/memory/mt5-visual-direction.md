The user preferred the Strategy board design, restyled with the original dashboard's colors and fonts, over the previous dashboard and explicitly approved keeping it in the real app.

**Why:** The user said it looked better than the current dashboard and asked to make the change. Earlier exploration-only restrictions no longer apply to this approved design.

**How to apply:** Preserve this approved visual direction in future maintenance. Exploration of additional designs is not permission to replace the real dashboard unless the user approves applying them.

The user approved reviewing the dashboard with clearly labeled fake trades in the preview.

**Why:** They requested sample trades to inspect the appearance and confirmed, "perfect, now is great."

**How to apply:** Keep design-review samples separate from real MT5 history and published live metrics.

**Rule:** Keep the dashboard dark permanently.

**Why:** The user explicitly requested a permanent dark theme while replacing the theme toggle with font-size controls.

**How to apply:** Do not reintroduce a light-theme toggle unless the user changes this requirement.
